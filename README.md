# KBank-Web API
KBank-Web API

📌 Sobre o projeto

Um sistema para você gerenciar suas financias com controle de dados em historico com banco.
Ele foi feito para o uso diario, ao em vez de tratar com planilhas gigantes, voce tem uma simples API que gerencia.
A proposta do projeto é organizar a vida financeira de forma simples e praticar uma API Rest
É um projeto de Web API Rest para estudos e praticas conforme o andamento do meu curso de ASP.NET Core
