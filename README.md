# KBank-Web API
KBank-Web API

API REST para gerenciamento de finanças pessoais, desenvolvida com C# e ASP.NET Core.

📌 Sobre o projeto

O KBank-Web API é um projeto de estudo que tem como objetivo desenvolver uma API para gerenciamento de finanças pessoais, permitindo organizar receitas, despesas e compras parceladas com persistência em banco de dados.

A proposta é oferecer uma alternativa simples ao controle financeiro por planilhas, centralizando os dados e as operações financeiras em uma API.

O projeto está sendo desenvolvido de forma incremental, acompanhando meus estudos de ASP.NET Core e aplicando conceitos de desenvolvimento backend na prática.
